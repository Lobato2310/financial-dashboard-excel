# Financial Dashboard – Excel

## 📊 Visão Geral
Dashboard financeiro desenvolvido em Excel com base no **Financial Sample Dataset da Microsoft**.
O objetivo é fornecer uma visão executiva sobre faturamento, lucro e desempenho ao longo do tempo.

## ❓ Perguntas de Negócio Respondidas
- Qual foi o faturamento total no período analisado?
- Qual foi o lucro total e a margem de lucro?
- Quais países são mais rentáveis?
- Qual segmento vende mais?
- O desempenho financeiro melhora ao longo dos anos?

## 📈 Principais Métricas
- Total Sales
- Total Profit
- Profit Margin (%)
- Sales por Segment
- Profit por Country
- Evolução anual de Sales e Profit

## 🛠️ Ferramentas Utilizadas
- Microsoft Excel
- Tabelas Dinâmicas
- Gráficos Dinâmicos
- Formatação Condicional
- Segmentadores (Slicers)
